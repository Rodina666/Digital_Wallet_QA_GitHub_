# Requirements

## REQ-01
The user can log in using valid credentials.

## REQ-02
OTP verification protects sign-in.

## REQ-03
Withdrawal must respect the available balance.

## REQ-04
Transfer amount validation rules must be enforced.

## REQ-05
A beneficiary must be valid before a transfer is completed.

## REQ-06
Protected APIs require a valid authorization token.

## REQ-07
Completed transactions must appear in transaction history.

> These requirements are portfolio/demo requirements derived from the project's traceability section.
